# HOUR / 디지털 모래시계

ESP32-C3 모래시계와 BLE로 연결하는 웹 디지털 트윈입니다. 이 저장소에는 웹페이지 파일만 있습니다.

## 페이지 열기

저장소의 GitHub Pages 주소(https://yeomjaemoo.github.io/digital-hourglass/)를 Chrome 또는 Edge에서 여세요. GitHub의 코드 보기 화면과 실제 웹페이지 주소는 다릅니다. 저장소 관리자는 Settings → Pages에서 게시 주소를 확인할 수 있습니다.

## 사용 순서

1. BLE 지원 Windows PC에서 블루투스를 켭니다.
2. BLE 펌웨어가 설치된 실물을 세워 전원을 켜고 보정이 끝날 때까지 가만히 둡니다.
3. 웹의 ‘블루투스 연결’을 눌러 자신의 Hourglass 장치를 선택합니다. 이름은 Arduino 시리얼 모니터 115200 baud에서 i를 입력하고 Enter로 전송하여 확인할 수 있습니다.
4. 위·아래 LED 표현색을 원하는 RGB 색으로 선택합니다. 색상은 웹에만 적용됩니다.
5. 슬라이더에서 1-10분을 고르고 ‘적용하고 다시 시작’을 누릅니다. 1-10분은 HourglassCore 1.1.0 기반 BLE 펌웨어가 필요합니다.
6. ‘소리 테스트’로 소리를 확인합니다. 완료 알림음은 페이지를 활성 상태로 두고 사용합니다.

연수생은 GitHub 로그인, Node.js, 로컬 서버 설치가 필요 없습니다. 페이지 접속에는 인터넷이 필요하고 장치 데이터는 자신의 PC와 ESP32 사이에서 BLE로 전달됩니다. 연결이 끊겨도 실물은 계속 작동합니다. 한 장치에 한 PC를 연결합니다.

3D 화면은 실제 LED 128칸과 화면 평면 기울기를 반영합니다. 카메라 원근감은 화면 연출이며 절대 3축 자세 추적은 아닙니다. WebGL이 지원되지 않으면 2D로 전환합니다. 새로고침 후 BLE는 다시 연결하세요.

## 게시 설정

파일 7개를 저장소 최상위에 두고 Settings → Pages → Deploy from a branch → main → /(root) → Save를 선택합니다. 별도 빌드나 사용자 작성 workflow 파일은 필요 없습니다. GitHub가 게시 작업을 실행하며 완료 상태는 Actions와 Pages에서 확인합니다.

웹 디자인을 업데이트할 때는 다섯 웹 파일을 함께 교체하세요. 페이지 갱신만으로 펌웨어가 변경되지는 않습니다.
